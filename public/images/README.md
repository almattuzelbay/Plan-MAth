# Optional photos

The landing page shows hand-made illustrations by default. To use photos instead, add free-license
images (e.g. from unsplash.com or pexels.com — both allow free commercial use) with exactly these names:

| File name             | Suggested search            | Shown in card        |
|-----------------------|-----------------------------|----------------------|
| open-enrollment.jpg   | "reviewing paperwork desk"  | Open enrollment      |
| new-job.jpg           | "first day office"          | Starting a new job   |
| turning-26.jpg        | "young adult laptop budget" | Turning 26           |
| baby.jpg              | "parents newborn"           | Having a baby        |

Landscape, about 1200×750 px, under 300 KB each. Missing files fall back to the illustrations automatically.
